## 核心公式

### 質量生成の統一公式

```
mass = M_ref × r^N

M_ref = Ω(e, τ_mH) × E₀         [基準質量スケール]
r     = 1/E₀ = 234.2137          [スケーリング比]
N     = ln(mass / M_ref) / ln(r) [スケーリング指数]
```

**使用定数: π, e, φ のみ**

### シンプレクティック演算子 Ω（BPS単純化）

```
Ω(τ₁, τ₂) = f(τ₁)·f'(τ₂) − f(τ₂)·f'(τ₁)

BPS固定点: f'(e) = 0  →  Ω(e, τ) = f'(τ)/e   [単純化]
ヒッグス基準: Ω(e, τ_mH) = f'(τ_mH)/e = 0.94573
```

BPS固定点が非可換テンソル積差分を1変数に圧縮し、ヒッグス粒子の勾配が全素粒子質量の共通前因子として機能する。

### 量子時間ベクトル

```
τ_vec(a) = τ(a) · e^{iθ}

τ(a) = E_H(a)/m_g    [半径: エネルギースケーリング]
θ(a) = Φ₂(a)         [向き: 時間の矢の非対称性]

光的条件: ds²=0 → cos(2θ)=0 → θ=45°
光速度不変: c = tan(45°) = 1  [τに依存しない固定点]
```
